# Expanded menu image provenance

The eight additional images in `frontend/public/menu/` are original illustrative category photographs generated for the expanded TableKind demonstration on 12 October 2026. They may illustrate multiple related dishes; they are not a promise of the exact appearance, portion size or ingredients of every associated menu item. No Andy’s Pizza photography or branding was copied.

## Creation and preparation

- Tool: the built-in image generation tool, with one distinct generation request per subject and no reference images.
- The project’s paid API key was not used for these assets.
- Each generated image was visually inspected for the requested subject, consistent warm ivory ceramics and pale stone setting, and absence of lettering or logos.
- Delivery: 800 × 800 pixel RGB WebP files, each below 150,000 bytes. Pillow performed proportional downscaling and WebP compression only; no composition edits were made. Quality is 82, except the meat platter at 76.
- Original PNG outputs remain in the image tool’s local output storage. The application uses the project copies, with no remote image requests.
