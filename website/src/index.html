A few things worth knowing

Before we sit down.

Do guests need an app or an account?

No app installation is needed. The prototype works in the browser, and guests can join a table without creating an account. Accounts are optional.

Can my restaurant start using it today?

We can arrange a guided fictional demonstration first. A live pilot needs an agreed workflow, access controls, operational checks and any required integrations. This website does not activate restaurant service.

Does Tablekind replace our existing POS?

No. Your restaurant’s workflow and POS must be assessed before a pilot. The current POS connector is a TEST simulator, not a connection to a commercial POS or fiscal system.

What does it cost?

Restaurant pricing and pilot terms have not been finalised. We want to understand the restaurant’s needs first. An enquiry is not a subscription or a payment commitment.

Can I try the full demo?

Yes, by arrangement. The guided application demo uses fictional tables, orders and payments. It stays separate from this presentation site and from future restaurant accounts.
